# 새벽 한 시, 달의 뒷면

> 비 오는 골목, 마감 종이 울린 뒤에 시작되는 이야기.
> 골목 끝 심야 카페에서 보낸 스무 밤.

브라우저에서 바로 실행되는 비주얼 노벨입니다. 설치도, 계정도 필요 없습니다.
순수 HTML · CSS · JavaScript — 외부 라이브러리 없이 동작합니다.

**▶ 플레이: https://weakold26.github.io/midnight-cafe-vn/**

## 등장인물

| | |
|---|---|
| **한도연** (31, 「달의 뒷면」 사장 · 수석 바리스타) | 커피를 내릴 때는 한 치도 흔들리지 않는 사람. 삼 년 동안 혼자 가게를 지켰고, 마감 후 단둘이 남으면 의외로 자주 넘어진다. 이름이 지워진 LP 한 장을 벽에 걸어 두고 있다. |
| **유하린** (23, 골목의 소리를 모으는 미대생) | 매일 밤 마감 직전에 찾아와 이어폰을 끼고 그림을 그린다. 주문은 늘 "아무거나". 두 달 동안 이 골목의 소리를 녹음해 졸업 작품을 만들고 있다. |

주인공은 방학 동안 이 가게에서 알바를 시작한 학생. 이름은 끝까지 묻지도, 말하지도 않습니다.

## 플레이 방법

- **화면 클릭 / Space / Enter** — 대사 진행 (출력 중이면 즉시 전체 표시)
- **선택지** — 화면의 선택지 터치, 또는 키보드 1 · 2 · 3
- **로그(L)** — 지나간 대사 다시 보기
- **자동(A)** — 대사가 끝나면 자동으로 진행
- **스킵(S)** — 선택지를 만날 때까지 빠르게 넘김
- **저장 / 불러오기** — 슬롯 3개 + 자동 저장 (`localStorage`)
- **설정** — 글자 속도(느리게/보통/빠르게/즉시), 배경음·효과음·빗소리
- 모바일(iPhone) 세로 화면에 맞춰 반응형으로 동작합니다.

## 엔딩

14개의 선택지와 두 사람의 호감도, 그리고 마감 후에 나눈 대화의 기억에 따라 **5종**의 엔딩이 있습니다.
타이틀 화면의 「엔딩 도감」에서 수집 현황을 볼 수 있습니다.

| | 결말 | |
|---|---|---|
| 01 | **마감 종이 울려도** | 도연 · 해피 엔딩 |
| 02 | **다음 계절의 원두** | 도연 · 노멀 엔딩 |
| 03 | **이어폰 한쪽씩** | 하린 · 해피 엔딩 |
| 04 | **그림의 뒷면** | 하린 · 노멀 엔딩 |
| 05 | **우리 셋의 마지막 주문** | 히든 엔딩 |

히든 엔딩은 두 사람의 호감도를 함께 쌓고, 마감 후의 비밀 두 가지(이름 지워진 LP의 사연, 완성된 곡)를 모두 들어야 열립니다.

## 구성

```
index.html              무대 · 타이틀 · 모달 마크업
css/style.css           4레이어 무대, 대사창, 선택지, 반응형
js/engine.js            엔진: 타자기·분기·호감도·세이브·자동·스킵·엔딩 도감
js/audio.js             WebAudio 로 만드는 배경음(재즈·로파이)·빗소리·효과음 (외부 음원 없음)
src/data/scenario.json  시나리오 725개 대사 노드 · 선택지 14개 · 엔딩 5종
assets/img/             배경 4종 · 캐릭터 스탠딩 8종 (WebP)
tools/                  시나리오 빌더 · 전수 시뮬레이터 · 자산 빌더
```

- 무대는 배경(크로스페이드 2겹) → 캐릭터(표정 전환·2인 동시 연출) → 이펙트(부유 입자·비네트·그레인) → UI 4레이어로 구성됩니다.
- 화자가 아닌 쪽 캐릭터는 자동으로 어두워지고, 두 사람이 함께 서면 좌우로 나뉘어 배치됩니다.
- 배경음은 코드로 합성합니다. 마감 후에는 로파이, 낮에는 재즈로 무드가 바뀌고, 비 오는 장면에서는 빗소리가 함께 깔립니다.
- 모든 일러스트는 생성형 이미지로 제작했고, 캐릭터는 같은 기본 이미지에서 표정만 바꿔 그려 일관성을 유지했습니다.
